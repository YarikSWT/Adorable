# Adorable Vite + React Template

Lightweight boilerplate for apps generated by Adorable.

## Stack

- **Vite 5** — dev server + bundler
- **React 18**
- **Tailwind CSS 3** — with CSS variables for theming
- **react-router-dom** — client-side routing
- **lucide-react** — icons
- **class-variance-authority + clsx + tailwind-merge** — style composition

No TypeScript, no SSR, no SWC native binary — everything is plain JS + esbuild.

## Dev

```
npm install
npm run dev
```

Opens on `http://localhost:5173` (host `0.0.0.0` so it's reachable from the proxy).

## Layout

```
index.html
vite.config.js         # port 5173, host 0.0.0.0
postcss.config.js
tailwind.config.js
jsconfig.json          # @/ → src/
src/
  main.jsx             # React root
  App.jsx              # router
  index.css            # tailwind + css vars
  pages/Home.jsx       # landing page
  components/ui/       # shadcn-style primitives
  lib/utils.js         # cn() helper
```
